Repository Structure Update (20.10.2026)

> Repository structure update effective October 20, 2026.

## English

- **Main branch update:** starting from October 20, 2026, the `main` branch serves as the showcase of the mod.
- **Source code branches:** the mod's source code is maintained in separate branches named according to the Minecraft version, using the `MC-{version}` format (e.g., `MC-1.21.1`).

## Русский

- **Изменение основной ветки:** с 20.10.2026 ветка `main` используется как витрина мода.
- **Ветки с исходным кодом:** исходники мода находятся в отдельных ветках, названия которых соответствуют версии Minecraft, в формате `MC-{version}` (например, `MC-1.21.1`).

## Українська

- **Зміна основної гілки:** з 20.10.2026 гілка `main` використовується як вітрина моду.
- **Гілки з вихідним кодом:** вихідний код моду зберігається в окремих гілках, назви яких відповідають версії Minecraft, у форматі `MC-{version}` (наприклад, `MC-1.21.1`).
